# Podium Design System - Components Index

Welcome to the Podium Design System components index. This document serves as a guide to the various components available for use in your web application dashboard. Each component is designed to be reusable and consistent with the overall design guidelines.

## Components Overview

### Buttons
Buttons are essential for user interactions. They come in various styles and sizes to accommodate different use cases.

- **Primary Button**: Used for main actions.
- **Secondary Button**: Used for less prominent actions.
- **Tertiary Button**: Used for minimal emphasis actions.

### Cards
Cards are versatile containers that can hold various types of content. They can be used for displaying information, images, or actions.

- **Standard Card**: Basic card layout for general use.
- **Image Card**: Card layout that includes an image.
- **Action Card**: Card layout designed for specific actions.

### Modals
Modals are overlays that display content above the main application interface. They are used for critical actions, confirmations, forms, or information that requires focused user attention.

- **Standard Modal**: General-purpose modal for forms and content display.
- **Confirmation Modal**: Modal for confirming critical user actions (delete, save, etc.).
- **Information Modal**: Modal for displaying read-only information.
- **Form Modal**: Modal containing input fields and form controls.
- **Full-Screen Modal**: Large modal for complex interfaces like tables or editors.

[View full Modal documentation](./modal.md)

### Forms
Forms are used for user input and data collection. They include various input types and validation states.

- **Text Input**: Standard input field for text.
- **Checkbox**: Input for binary choices.
- **Radio Button**: Input for selecting one option from a set.

### Navigation
Navigation components help users move through the application.

- **Sidebar Navigation**: Vertical navigation for primary sections.
- **Top Navigation**: Horizontal navigation for quick access to key areas.

### Alerts
Alerts provide feedback to users about the status of their actions.

- **Success Alert**: Indicates successful actions.
- **Error Alert**: Indicates errors or issues.
- **Warning Alert**: Indicates caution or important information.

### Tooltips
Tooltips provide additional information when users hover over elements.

- **Standard Tooltip**: Basic tooltip for additional context.
